# TapNSwitch 🪓
The axe throwing scoreboard that’s faster than a bullseye.

Because let’s be honest: doing mental math while holding a sharp object isn't always the best idea. TapNSwitch is a lightweight, intuitive scoring application designed for axe throwing enthusiasts and venues. Whether you're throwing in a backyard or a professional arena, we handle the numbers so you can focus on the stick.
